# AI-Powered Web Brochure Generator

## 📌 Overview
This project extracts `h1` and `p` tag data from a given webpage and uses AI to generate a professional brochure. It’s ideal for marketers, students, and developers who want to quickly convert web content into polished promotional material.

## 🚀 Features
- Extracts headings (`h1`) and paragraphs (`p`) from any webpage.
- Uses AI to generate a structured brochure layout.
- Produces professional, ready-to-use content.
- Lightweight and beginner-friendly.

## 🛠️ Tech Stack
- **Python** (for web scraping and automation)
- **BeautifulSoup / Requests** (to extract HTML content)
- **AI API** (for brochure generation)
